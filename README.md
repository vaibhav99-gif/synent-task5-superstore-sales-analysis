# Superstore Sales Data Analysis

## Project Overview
This project analyzes Superstore sales data to understand monthly revenue trends, identify top-selling products, and compare profitability across product categories.

## Objectives
- Analyze monthly sales revenue.
- Identify the five products with the highest sales.
- Compare total profit across product categories.
- Summarize important business findings.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load and inspect the Superstore dataset.
2. Check missing values and duplicate records.
3. Convert date and numeric columns to appropriate data types.
4. Calculate monthly revenue.
5. Identify top-selling products.
6. Analyze profit by product category.
7. Summarize the findings.

## Files
- `superstore_sales_analysis.ipynb` — notebook containing the code, explanations, analysis, and visualizations.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the Superstore CSV file when prompted.
3. Run the cells from top to bottom.

## Dataset
The Superstore dataset was obtained from Kaggle and contains information about orders, sales, products, and profits.
Dataset Link:https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
